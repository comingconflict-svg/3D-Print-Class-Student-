# The First Layer Project

Give overlooked teenagers a 3D printer, an open curriculum, and a path from first print to real engineering — then require them to earn the machine through milestones.

Founded by Thomas Smith (Kentucky).

## The problem

Many smart, motivated kids are not treated as “gifted.”

Schools overlook them. Families and communities often expect them to take the same work their parents do — farming, factory jobs, and other local trades that are honorable but not the only future. Homeschoolers are especially likely to be steered that way.

These teens are not short on intelligence. They are short a first, physical way into STEM.

## The solution

**3D printing.** It is tangible. A kid can see it, hold it, fail, and try again.

The path is short and real:

`toy → tool → fitted part → mechanism → electrical / robotics / aerospace`

The First Layer Project awards a **printer, filament, and curriculum** to selected teens or groups (ages 13–18) in:

- homeschools
- church-led youth groups
- rural and agricultural communities
- other socioeconomically underserved settings

Awards are not no-strings gifts. Recipients must pass **milestones** at set intervals (required projects and/or checks). Miss them without cause and support pauses, or the kit moves to the next waitlisted group.

## Open curriculum

The curriculum is open source and meant to stay alive. Educators and students can improve it as it is used.

Goal: a platform that can replicate this class anywhere.

Current draft lives in the two repos linked above.

## Milestone ladder (draft)

| When | Gate | Pass looks like |
| --- | --- | --- |
| Week 2 | First print | Unbox, set up, print a calibration part |
| Month 1 | First original part | Design or remix one useful object + short write-up |
| Month 3 | Skill project | Multi-part assembly or a part that has to fit something else |
| Month 6 | Pathway project | Work that points toward electronics, robotics, aerospace, or a real tool at home / farm / shop |
| Ongoing | Check-ins | Photos, print files, what failed, what changed |

**Groups** (co-op, church, rural club): one accountable adult + named teen leads. The machine is shared; milestones are still signed so no one hides.
