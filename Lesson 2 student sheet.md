## Mission
Find one small, legal model. Slice it for the Prusa CORE One.

## Where to look
- https://www.printables.com
- https://makerworld.com
- The Printables tab inside PrusaSlicer also works

## Hunt checklist
- [ ] I opened the Lesson 2 file on GitHub
- [ ] I can say what the object is in one sentence
- [ ] It looks like it will print in under 2 hours
- [ ] It can sit flat on the bed
- [ ] It does not need a forest of supports
- [ ] I wrote the designer name and license

## PrusaSlicer steps
1. Import the file (drag it onto the Plater, or use the Add button)
2. Printer = Prusa CORE One, HF0.4 mm nozzle
3. Filament = Generic PLA (or the class PLA preset)
4. Print settings = Class_PLA_0.20
5. Lay it flat on the bed. Use Place on Face if you need to.
6. Click Slice now
7. Open Preview and use the layer slider
8. Write time and filament
9. File > Save project, and keep the 3MF
