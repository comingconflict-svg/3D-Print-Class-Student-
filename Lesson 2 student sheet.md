## Mission
Find one small, legal model. Slice it for the QIDI Q2.

## Where to look
- https://www.printables.com
- https://makerworld.com

## Hunt checklist
- [ ] I opened the Lesson 2 file on GitHub
- [ ] I can say what the object is in one sentence
- [ ] It looks like it will print in under 2 hours
- [ ] It can sit flat on the bed
- [ ] It does not need a forest of supports
- [ ] I wrote the designer name and license

## OrcaSlicer steps
1. Import the file
2. Printer = Qidi Q2, 0.4 mm
3. Filament = PLA
4. Process = Class_PLA_0.20
5. Lay it flat on the plate
6. Slice
7. Open Preview
8. Write time and filament
9. Export 3MF
